# Smart Library Management System (Angular)

4 pages: Home, About Library, Books, Registration.

## Run
```bash
npm install
npm start          # http://localhost:4200
```

## Build / GitHub Pages
```bash
npm run build:ghpages
# dist/library-management/browser ke andar ki files ko gh-pages branch par upload karein
```
Hash routing (`#/books`) use hui hai, isliye GitHub Pages par refresh karne par 404 nahi aayega.
